# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The ReviewFlow team takes security vulnerabilities seriously.

If you discover a security vulnerability within ReviewFlow, please **DO NOT** open a public issue.
Instead, send an email directly to security@reviewflow.com with:

1. Type of issue (e.g. cross-tenant data access, auth bypass, injection)
2. Detailed steps to reproduce the vulnerability
3. Affected components and versions
4. Proof-of-concept payload or request if available

We will acknowledge receipt of your vulnerability report within 24 hours and provide a fix timeline.
